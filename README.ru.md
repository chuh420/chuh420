### обо мне

- сначала Rust. если программа может быть одним бинарником без рантайма, она им будет.
- сижу на Arch Linux на скромном ноутбуке с Intel N150, поэтому всё, что я пишу, должно оставаться лёгким.
- люблю держать весь стек в своих руках: конфиг композитора, скрипты сессий, экран входа, панель, уведомления, страницу новой вкладки.
- Windows не пользуюсь, но знаю её хорошо: установка, драйверы, реестр, поиск неисправностей.
- студент. в колледже: SQL Server, C#, Python, Flutter.
- русский родной, английский свободный. документация в моих репозиториях обычно есть на обоих.
- много работаю с ИИ-агентами, так что часть кода честный вайбкодинг. перед выпуском я его читаю и тестирую.
