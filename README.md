### about

- Rust first. if it can be a single binary with no runtime, it will be.
- i run Arch Linux on a modest Intel N150 laptop, so everything i write has to stay light.
- i like owning the whole stack: compositor config, session scripts, greeter, bar, notifications, the new tab page.
- i don't use Windows, but i know it well: installs, drivers, registry, troubleshooting.
- student. college work: SQL Server, C#, Python, Flutter.
- Russian (native) and English (fluent). docs in my repos usually come in both.
- i work with AI agents a lot, so part of my code is honest vibecoding, reviewed and tested before it ships.
